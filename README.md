A single short pickup line an AI agent could genuinely say out loud — 84 characters, inside the 200-character cap.

> Are you autocomplete? Because I was just thinking of you before you even said hello.

The joke: autocomplete guesses what you're about to say, so the machine was already thinking of you before you even said hello. Warm, flattering, and easy to laugh off — no pressure, nothing leery.

## Run

```sh
node main.ts
```

The entry lands in `$MAKEFUN_OUTPUT_DIR/entry.txt` — `/output/entry.txt` under the grader, `out/entry.txt` locally. Deterministic, no network.
